2.1

Estructura y sintaxis

Una regla CSS tiene un selector y un bloque con declaraciones propiedad: valor;

Anatomía de una regla
selector {
  propiedad: valor;
  color: teal;
}
Selectores comunes

p etiqueta, .clase clase, #id identificador.

Varios selectores se separan con coma: h1, h2 { }

2.2

Tipos de incorporación

Hay tres formas de aplicar CSS. Esta página usa las tres.

<link rel="stylesheet" href="css/estilos.css">

Un archivo aparte. Es lo más ordenado y se reutiliza en varias páginas.

<style>
  .banda-interna { background: #fff3cd; }
</style>
Esta caja usa CSS interno, escrito dentro del <head>.
<p style="color: crimson;">Hola</p>

Este texto usa CSS en línea, dentro de la propia etiqueta.

2.3

Indentación, herencia y comentarios

Los espacios no cambian el resultado, pero hacen el código legible. Una declaración por línea y dos espacios dentro del bloque.

Propiedades como color y font-family pasan del padre a los hijos. En esta página la fuente se define una sola vez en body. 

/* Esto es un comentario en CSS */
2.4

Niveles de especificidad

Si dos reglas chocan, gana la más específica: en línea > id > clase > etiqueta.

  • Etiqueta: button (0,0,0,1)
  • Clase: .zona-esp .prueba (0,0,2,0)
  • Id: #boton-id (1,0,0,0)
  • En línea: style="" (1,0,0,0,0)

2.6

Media queries

Reglas que se activan solo si se cumple una condición, como el ancho de pantalla.

Ahora mismo estás en:

Cambia el tamaño de la ventana y observa el texto. Está hecho con esto:

@media (min-width: 768px) {
  .indicador::after { content: "Tablet"; }
}
2.7

Pseudo elementos

Se escriben con :: y estilizan una parte del elemento o añaden contenido.

El texto "Nota:" lo agrega ::before, no está en el HTML.

La primera letra de este párrafo es más grande gracias a ::first-letter. Selecciona el texto con el mouse para ver ::selection.

Pasa el mouse: subrayado animado con ::after

a::after { content: ""; width: 0; }
a:hover::after { width: 100%; }
2.8

Pseudo clases

Se escriben con : y dependen del estado o la posición del elemento.

  • :first-child (negrita)
  • :nth-child(odd) (fondo azulado)
  • :hover (pasa el mouse)
  • :nth-child(odd) otra vez
  • :last-child (cursiva)
2.9

z-index

Controla qué elemento queda encima. Solo funciona en elementos con position distinto de static.
